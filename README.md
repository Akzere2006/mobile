# Volt — универсальный шаблон интернет-магазина

## Требования
Node.js 18+ и npm.

## Запуск
```bash
npm install
npm run dev
```
Для production-сборки: `npm run build`, предпросмотр: `npm run preview`.

## Адаптация под другую нишу
- `src/config/store.config.js` — название, слоган, акцентный цвет, контакты, категории, преимущества, ссылки и баннер.
- `src/data/products.js` — демонстрационные товары, цены, характеристики, рейтинги и изображения.
- `src/styles/global.css` — дизайн-токены, сетки, отступы и брейкпоинты.
- `src/components/` — переиспользуемые компоненты; `src/pages/` — страницы.

Изображения в демонстрационных данных загружаются с Unsplash Source URL. Для production замените их собственными стабильными изображениями/CDN. Корзина и избранное сохраняются в LocalStorage. Оформление заказа демонстрационное: персональные данные не отправляются и платежей нет.
